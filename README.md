<h1 align="center" id="title">🚀 Gemini Clone Web App</h1>

<p id="description">The Gemini Clone Web App is a sophisticated and user-friendly cryptocurrency trading platform designed to replicate the core functionalities of the popular Gemini Exchange. Built using React.js this web application integrates seamlessly with the Gemini API to provide real-time cryptocurrency market data and trading features. The platform allows users to track cryptocurrency prices execute trades and monitor their portfolio in a dynamic and responsive environment.</p>

<h2>🧐 Features</h2>

Here're some of the project's best features:

*   ✅ Real-time Cryptocurrency Data – Fetch live market prices using the Gemini API.  
    ✅ User-friendly Trading Interface – Buy and sell cryptocurrencies with an intuitive UI.  
    ✅ Order Book & Trade History – View real-time order book updates and transaction history.  
    ✅ Price Charts & Market Trends – Visualize price movements with interactive charts.  
    ✅ Secure & Scalable – Designed with performance and security best practices.  
    ✅ Responsive Design – Fully optimized for desktop and mobile devices.

<h2>🛠️ Installation Steps:</h2>

<p>1. Clone the repository:</p>

```
git clone https://github.com/hemanthyt/gemini-clone-react.git
```

<p>2. Move to root folder</p>

```
cd gemini-clone
```

<p>3. Install dependencies:</p>

```
npm install
```

<p>4. Set up your environment variables (if required for API keys).</p>

<p>5. Start the development server:</p>

```
npm run dev
```

  
  
<h2>💻 Built with</h2>

Technologies used in the project:

*   React.js – Frontend framework for building interactive UI.  
*   Gemini API – Fetching real-time market data and executing trades.  
*   Axios / Fetch API – Handling API requests.  
*   React Router – Enabling smooth navigation between pages.  
*   Tailwind CSS – Modern and sleek UI styling.
